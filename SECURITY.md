# Security Policy

## Scope

Marcus Monster Slayer is a single-player, offline desktop game. It has no network
services, no account system, and no telemetry. The realistic attack surface is
limited to:

- Malicious project/config files if you build from an untrusted fork.
- Third-party plugin or engine vulnerabilities (report those upstream).

## Reporting

Email the maintainer in `CODEOWNERS`, or open a
[private security advisory](../../security/advisories/new). Please do not file a
public issue for anything you believe is exploitable.

Expect an acknowledgement within 7 days.

## Supported versions

Only `main` and the most recent tagged release receive fixes.
