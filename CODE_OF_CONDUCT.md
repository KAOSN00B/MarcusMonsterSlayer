# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment. Unacceptable behaviour
can be reported to the maintainer listed in `CODEOWNERS`. Maintainers may remove,
edit, or reject contributions and comments that violate this code, and may ban
repeat offenders.

The full text is available at the link above.
